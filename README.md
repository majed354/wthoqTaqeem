# وثوق — Wothoq

واجهة عربية تساعد المستخدم على فهم موثوقية التقييمات بدل الاكتفاء بمتوسط النجوم الخام.

## النسخة الحالية

- تحليل تجريبي لرابط منشأة من Google Maps.
- مقارنة منشأتين بعد التصحيح.
- فصل خطر التلاعب عن درجة الثقة في التحليل.
- تفسير الإشارات المؤثرة ومحاكاة أثر تغيير أوزانها.

البيانات المعروضة في هذه النسخة محاكاة ولا تصف منشآت حقيقية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## النشر

المشروع مهيأ للنشر على Netlify باستخدام الأمر `npm run build` والمجلد `dist`.
