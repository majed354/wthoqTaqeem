# وثوق — Wothoq

واجهة عربية تساعد المستخدم على فهم موثوقية التقييمات بدل الاكتفاء بمتوسط النجوم الخام.

## النسخة الحالية

- استيراد اسم المنشأة وتصنيفها ومدينتها وتقييمها وعدد التقييمات من Google Places API (New).
- مقارنة البيانات الخام لمنشأتين من رابطين حقيقيين.
- نموذج تجريبي مستقل يوضح شكل تحليل الموثوقية القادم.
- فصل خطر التلاعب عن درجة الثقة في التحليل.

هوية المنشأة ومتوسطها وعدد تقييماتها بيانات حقيقية عند استخدام رابط فعلي. درجة الوثوق وخطر التلاعب لا يُحسبان بعد لعدم توفر بيانات المراجعات التفصيلية.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local
npm run dev
```

أضف مفتاحًا خادميًا إلى `.env.local` باسم `GOOGLE_MAPS_API_KEY`. لا تستخدم بادئة `VITE_` ولا ترفع ملف البيئة إلى GitHub.

## النشر

المشروع مهيأ للنشر على Netlify باستخدام الأمر `npm run build` والمجلد `dist`، ودالة الاستيراد موجودة في `netlify/functions/place.ts`.

في Netlify أضف متغير البيئة `GOOGLE_MAPS_API_KEY` من:

`Project configuration → Environment variables`

اجعله متاحًا للدوال وبيئات Production وDeploy Previews، ثم أعد النشر. يجب تقييد المفتاح في Google Cloud ليعمل مع Places API (New) فقط.
